## How it works

`draw.py` (build-time only, Pillow) draws the 1024×1024 image and saves it as
`entry.png`. `main.py` (Python 3.13, standard library only) copies the
committed `entry.png` to `/output/entry.png` and verifies the copy with a
SHA-256 check, so both grading runs write byte-identical output. No network
at run time.
